# ✅ React Frontend готов к развертыванию на Windows Server

## 📦 Готовые архивы для развертывания

- **hlviewer-frontend-deployment.zip** (320KB) - для Windows
- **hlviewer-frontend-deployment.tar.gz** (319KB) - универсальный

## 📁 Содержимое архива

```
deployment/
├── README_DEPLOYMENT.md     # Подробная инструкция по развертыванию
├── simple-server.js         # HTTP сервер Node.js (опционально)
├── start-server.bat         # Скрипт запуска для Windows (опционально)
└── dist/                    # Скомпилированное приложение
    ├── index.html           # Главная страница
    ├── web.config           # Конфигурация для IIS
    ├── .htaccess           # Конфигурация для Apache
    └── assets/             # CSS, JS и другие ресурсы
        ├── index-*.css     # Стили приложения
        └── index-*.js      # JavaScript приложения
```

## 🚀 Варианты развертывания

### Вариант 1: Статические файлы (рекомендуемый)

**Преимущества:**
- ✅ Не требует Node.js на сервере
- ✅ Максимальная производительность
- ✅ Простая настройка
- ✅ Высокая надежность

**Шаги:**
1. Распаковать архив на Windows сервере
2. Скопировать содержимое папки `dist/` в веб-сервер
3. Настроить веб-сервер (используйте прилагаемые файлы конфигурации)

### Вариант 2: Node.js сервер

**Преимущества:**
- ✅ Не требует настройки веб-сервера
- ✅ Готовый к работе сервер
- ✅ Простой запуск одним кликом

**Требования:**
- Node.js 18+ на Windows сервере

**Шаги:**
1. Распаковать архив на Windows сервере
2. Двойной клик по `start-server.bat`
3. Приложение будет доступно на http://localhost:3000

## 🔗 API Requirements

Приложение ожидает, что backend API доступен по адресу `/api/` относительно адреса приложения.

**Примеры endpoint'ов:**
- `GET /api/lines/` - получение линий
- `GET /api/edit/` - архив вмешательств
- `GET /api/hourly/` - часовые данные
- `GET /api/daily/` - суточные данные
- `GET /api/edit_counts/` - счетчики изменений
- `GET /api/sys_counts/` - системные счетчики

## 📋 Checklist перед развертыванием

- [ ] Backend API запущен и доступен
- [ ] Настроены CORS заголовки на backend
- [ ] Проверена работа всех API endpoint'ов
- [ ] Выбран способ развертывания (статические файлы или Node.js)
- [ ] Подготовлен веб-сервер (если используются статические файлы)

## 🆘 Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на ошибки
2. Убедитесь, что backend API доступен
3. Проверьте настройки веб-сервера
4. Обратитесь к файлу `README_DEPLOYMENT.md` для детальных инструкций
